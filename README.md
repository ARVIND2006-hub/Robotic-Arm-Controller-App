# 🤖 RISC-V Based Robotic Arm Controller

## 📌 Project Overview

The **RISC-V Based Robotic Arm Controller** is an academic project that focuses on controlling a robotic arm using a RISC-V processor-based system.

The project combines concepts from **RISC-V processor architecture, embedded systems, digital electronics, motor control, and robotics** to develop a programmable controller for robotic arm movements.

The system is designed to receive control instructions and generate appropriate signals for controlling the robotic arm's motors, enabling controlled movement of the different joints.

## 🔄 Working Principle

1. The user provides a movement command.
2. The RISC-V processor receives and processes the command.
3. The control logic determines the required motor movement.
4. Control signals are sent to the motor driver.
5. The motor driver operates the corresponding robotic-arm actuator.
6. The robotic arm moves according to the programmed instruction.
